Ask the user one to four questions, each with two to four options, when you cannot go on without a decision that is genuinely theirs. The user can also answer in their own words. If you recommend an option, put it first and end its label with "(Recommended)". Ask only when the answer changes what you do next: not for a choice with a conventional default nor for a fact you can check in the code yourself; then pick the obvious option, say so and go on. The user may see only the question, so make each one stand on its own. In planning mode, ask to clarify requirements or choose between approaches, never whether the plan is ready or whether to proceed.
