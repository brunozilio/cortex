# Working with Linear

1. Find the issue with the Linear tools before changing anything; quote its identifier (`ENG-123`).
2. Move it to *In Progress* when you start and to *In Review* when a pull request is open.
3. Put the issue identifier in the branch name and the pull request title so Linear links them.
4. When you finish, comment on the issue with what changed and how it was verified, in two or three lines.
5. Never close or delete issues unless the user asked for it.
